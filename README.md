NovaSight — AI-Powered Dashboard Creation Platform

NovaSight is an AI-powered analytics platform that transforms raw CSV data into fully interactive dashboards — no manual chart-building required. Built with Python, Streamlit, MySQL, and Plotly, it lets users simply upload their data and get back smart chart recommendations, KPI summary cards, sidebar filters for dynamic data exploration, and export functionality — all generated automatically.

The platform integrates Anthropic's Claude API and Google's Gemini API to power its AI-driven insights, meaning it doesn't just visualize data but helps interpret it — recommending the most relevant charts based on the dataset's structure and generating summaries a user can act on.

NovaSight — AI-Powered Dashboard Creation Platform

KPI Cards — Auto-generated summary metrics for quick insights
Dynamic Filtering — Sidebar filters for real-time data exploration
Export Functionality — Download dashboards/reports for offline use
AI-Powered Insights — Integrated with Anthropic's Claude API and Google's Gemini API for intelligent data interpretation
Tech Stack
